# Sources and provenance

The scientific model uses public NASA, NAIF/JPL, IAU, and peer-reviewed data alongside published astronomical conventions. Links and citations below document every external dataset, physical constant, visual texture, and software library used by ILARGI, separately from initial-concept candidates that were not adopted.

Curated catalog coordinates in [`ilargi/sites.py`](../ilargi/sites.py) remain demonstration locations and have not been individually revalidated against an authoritative coordinate catalog in this review.
